# 🎮 原神启动插件

一款为 [AstrBot](https://github.com/AstrBotDevs/AstrBot) 设计的原神启动插件，当检测到"原神"关键词时自动回复原神圣经语录



---

## ✨ 功能特性

- 🔍 **智能检测** - 自动识别消息中的"原神"关键词
- 💬 **随机回复** - 从语录库中随机选择一条回复
- ⏱️ **冷却控制** - 支持设置触发冷却时间，避免频繁打扰
- 🎨 **自定义语录** - 可自由添加、删除、修改原神圣经语录
- 🔒 **白名单模式** - 支持仅在指定群聊启用

---

## 📖 使用方法

在群聊中发送包含"原神"关键词的消息，机器人将自动回复一条随机语录。

### 💡 示例

> **用户：** 今天玩了原神
> 
> **机器人：** 你说的对，但是《原神》是由米哈游自主研发的一款全新开放世界冒险游戏。游戏发生在一个被称作「提瓦特」的幻想世界，在这里，被神选中的人将被授予「神之眼」，导引元素之力。你将扮演一位名为「旅行者」的神秘角色，在自由的旅行中邂逅性格各异、能力独特的同伴们，和他们一起击败强敌，找回失散的亲人——同时，逐步发掘「原神」的真相。
